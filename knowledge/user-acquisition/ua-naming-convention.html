A naming convention for UA campaigns, ad groups and creatives

One pattern for campaigns, ad groups and creatives so anyone can read a report at a glance.

When several people run campaigns across many games and networks, names are the cheapest form of documentation. A good convention lets anyone read a report and know the game, platform, network, country and goal of each line without opening the campaign.

Campaign

<Game>_<Platform>_<Network>_<Country>_<Type>_<Name>_<YYMMDD>
  • Game: a short code of about 3 letters.
  • Platform: A for Android, i for iOS.
  • Network: a fixed short code per network, for example FB, GG, Uni, Tik.
  • Country: ISO alpha-2 code, or Global.
  • Type: the optimization goal, such as CPI, CPA, ROAS or Retention.
  • Name: the event or idea being tested.
  • Date: the day the campaign was created.

Example: ABC_A_GG_US_CPA_Level10_261020

Ad group, ad set or creative pack

<Game>_<Network>_<Country>_<AdType>_<GroupName>

Ad type is Ban (banner), Vid (video) or Play (playable). The group name starts with the creative number so packs sort in order, for example ABC_FB_US_Vid_13Gameplay.

Creative

<Game>_<Language>_<AdType>_<No.>_<CreativeName>

Leave the language out for English and add it only for localized versions, for example ABC_JP_Vid_1_Gameplay30s.

Why it pays off

  • Reports can be split by any field with a simple text split, no manual tagging.
  • Creative numbers stay the same across networks, so the same idea can be compared everywhere.
  • New team members learn the structure from the names alone.
